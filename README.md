# MeshPeak

5×5 グリッドの標高ラスタ CSV を読み込み、DN値のマトリクスと 3D 地形で学べる教育用 Web ツール(TRON 風デザイン)。

- DN値マトリクス(クリックで選択 / ダブルクリックで値を編集 → 3D がリアルタイム変形)
- 3D表示: ブロック(ラスタセル)/ サーフェス、高さ強調、水位シミュレーション、傾斜・斜面方位の解析
- CSV 読込(ファイル / ドラッグ&ドロップ / 貼り付け)・保存、サンプル地形 8 種(`samples/*.csv`)

## CSV 形式
```
10,20,30,20,10
20,70,110,70,20
30,110,180,110,30
20,70,110,70,20
10,20,30,20,10
```
カンマ・空白・タブ区切り。`#` 始まりの行は無視。2×2〜32×32 に対応(教育用途の推奨は 5×5)。

## GitHub Pages
